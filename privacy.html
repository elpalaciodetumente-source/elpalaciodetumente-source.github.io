Política de privacidad

Última actualización: 28 de octubre de 2026.

Fisiologia Facil Publicador («la aplicación») es una herramienta privada de un solo usuario: el propietario de los canales de YouTube Fisiologia facil, Easy Physiology y Einfache Physiologie. Esta política explica qué datos usa, cómo los guarda y cómo se borran.

Servicios de la API de YouTube

La aplicación usa los Servicios de la API de YouTube (YouTube API Services). Al usarla aceptas las Condiciones del servicio de YouTube. Además, se aplica la Política de privacidad de Google.

Qué datos usa

  • Un token de acceso de Google (OAuth 2.0) para los canales del propietario, con permiso para subir y gestionar sus videos en YouTube.
  • Los archivos que el propietario quiere publicar: videos, miniaturas, subtítulos, títulos, descripciones y etiquetas.
  • Los identificadores de los videos subidos y su estado, para no subir dos veces el mismo video.

La aplicación no usa cookies ni rastreadores y no recoge datos de otras personas.

Para qué los usa

Solo para subir y programar los videos del propietario en sus propios canales y para comprobar que la subida terminó bien. No lee datos de otros usuarios, no publica comentarios, no muestra anuncios y no usa los datos para ningún otro fin.

Con quién se comparten

Con nadie. Los datos solo se envían a la API de YouTube de Google. No se venden ni se ceden a terceros.

Cómo se guardan

El token se guarda cifrado en un almacenamiento privado al que solo accede la aplicación. Los datos obtenidos de la API de YouTube (identificadores y estado de los videos) se guardan como máximo 30 días; pasado ese plazo se actualizan o se borran.

Cómo retirar el acceso y borrar los datos

  • Puedes retirar el acceso de la aplicación en cualquier momento en la página de configuración de seguridad de Google: security.google.com/settings/security/permissions. Al hacerlo, el token deja de funcionar.
  • Al retirar el acceso, la aplicación borra el token y los datos de la API que tuviera guardados en un plazo máximo de 7 días.
  • También puedes pedir el borrado de todos los datos escribiendo a fisiologia.facil.yt@gmail.com. Se borran en un plazo máximo de 7 días.

Privacy Policy (English)

Last updated: 28 October 2026.

Fisiologia Facil Publicador ("the app") is a private, single-user tool used only by the owner of the YouTube channels Fisiologia facil, Easy Physiology and Einfache Physiologie.

YouTube API Services

The app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

Data used

A Google OAuth 2.0 token for the owner's own channels; the files the owner chooses to publish (videos, thumbnails, captions, titles, descriptions, tags); and the IDs and status of uploaded videos, to avoid duplicate uploads. The app uses no cookies or trackers and collects no data about other people.

Purpose

Only to upload and schedule the owner's videos on his own channels and to confirm each upload. The app does not access other users' data, does not post comments or ads, and does not use data for any other purpose.

Sharing

Data is sent only to Google's YouTube API. It is never sold or shared with third parties.

Storage

The token is stored encrypted in private storage accessible only to the app. Data obtained from the YouTube API (video IDs and status) is kept for no more than 30 days, after which it is refreshed or deleted.

Revoking access and deleting data

  • You can revoke the app's access at any time via the Google security settings page: security.google.com/settings/security/permissions.
  • When access is revoked, the app deletes the token and any stored API data within 7 days.
  • You can also request deletion of all data by writing to fisiologia.facil.yt@gmail.com. Data is deleted within 7 days.
